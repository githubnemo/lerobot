## 3. Critical Bugs Found & Fixed
1. **Why 30 Hz custom script failed vs. 10 Hz native `lerobot-rollout`**:
   - At 30 Hz (`0.30–0.33 s` RTT), `delay = 10` ticks discarded `actions[:10]` (the accurate `H1`–`First-5` horizon) and executed only the noisy tail `actions[10:22]`.
   - `run_mac_vam_rpc.py` also applied a custom 6-step linear blend and `rpc_server.py` applied 2-pass Nyquist smoothing (`bdb3fa9c3` removed both, read task from config, defaulted `--num-episodes 1`).
2. **EXPO RL completely bypassed RTC (`b0f84139a`)**:
   - `rpc_server.py` called unguided `decoder.sample_actions` when `expo_critic` was active while the client sliced `actions[delay:]`. Fixed to run a single RTC-guided `predict_action_chunk` pass with residual & exploration ramped from `delay`.
3. **Untrained `MultiFrameSuccessDetector` auto-terminating episodes (`0bf5a9433`)**:
   - Added `self.detector_pretrained` guard so human `'s'`/`'f'` keypresses are the sole reward signal unless a pretrained detector checkpoint is explicitly passed.
4. **Cosmos 3 `history_size=1` bugs & RunPod stop (`7d9c6b22b`, `6fb034315`)**:
   - Audit caught `_maybe_preload_to_ram()` silently overwriting `history_size=1` back to 5 frames, plus `KeyError: 0` in sparse val preload. Stopped RunPod `sfijmgdsbo1wgi` (`EXITED`, all RunPod pods off, zero idle spend).
5. **LoRA path resolution priority (`7d9c6b22b`)**:
   - Fixed `modeling_video_vam.py` to prefer `run_dir/best_backbone_lora.safetensors` over stale `repo_root / lora_ckpt`.
6. **`SOFollowerRobotConfig.__post_init__` MRO bug (`0d1281636`)**:
   - Fixed MRO shadowing so `--robot.record_all_telemetry=true` enables all 48-D STS3215 telemetry channels (`pos`, `vel`, `load`, `current`, `voltage`, `temperature`, `moving`, `status`).
